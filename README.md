## Run it

```sh
node main.ts
```

## The entry

Line 1 explains a toaster in a single vivid sentence built on one analogy; line 2 says in one sentence why that analogy works — what it maps and what it leaves out. The program writes the two lines to `/output/entry.txt` (UTF-8, 1–400 characters, per the bounty gate).
